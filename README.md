# earjemp

Ear training app built with Vue 3, Vite and Vuetify.

## Setup
```bash
npm install
```

## Development
```bash
npm run dev
```

## Production build
```bash
npm run build
```

## Preview production build
```bash
npm run preview
```

## Lint
```bash
npm run lint
```

## Unit tests
```bash
npm run test:unit
```
